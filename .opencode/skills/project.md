# Skill: Project Management

Trigger: planning, ticket creation, standup updates, blockers.

Capabilities:
- Create Jira tickets with proper fields.
- Link tickets to Confluence docs.
- Track sprint progress.
- Update `PRD_ANALYSIS.md` when scope changes.

Jira Workflow:
1. Create Epic: `HT-0 MVP Habit Tracker`.
2. Create Stories under Epic.
3. Set Story Points (1-8).
4. Transition: Backlog -> In Progress -> Done.

Confluence Workflow:
1. Create design doc page.
2. Link from Jira ticket.
3. Update with architecture decisions.
