# Skill: Frontend Development

Trigger: React components, MUI styling, routing, API integration.

Capabilities:
- Scaffold Vite + React + TS.
- Configure MUI theme for premium minimal design.
- Implement responsive layouts with Grid.
- Use React Router v6.
- Use Axios with interceptors.
- Write React Testing Library tests.

Key Commands:
- `npm run dev`
- `npm run test`
- `npm run build`

Patterns:
- `pages/` for route-level components.
- `components/` for reusable UI.
- `hooks/` for custom logic.
- `services/` for API calls.
- `types/` for shared TS types.
