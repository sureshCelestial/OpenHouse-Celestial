# Skill: Testing & QA

Trigger: writing tests, running suites, verifying criteria.

Capabilities:
- Backend: Jest + Supertest for API integration.
- Frontend: React Testing Library + Jest for components.
- Coverage reporting.

Patterns:
- Test DB: separate PostgreSQL container or `TEST_DATABASE_URL`.
- Reset DB before each test suite.
- Mock timers for streak logic tests.
- Assert on HTTP status codes and response shapes.
